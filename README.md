## About the course

Develop a solid C# foundation and use bounded AI prompts to propose software designs and code changes. Validate inputs, choose suitable controls and object-oriented features, assess component behaviour and produce documentation that traces back to user specifications. AI is optional; the supplied projects run locally without API keys or third-party NuGet packages.

## Learning outcomes

- Determine basic software components using C# methodologies to meet functional specifications.
- Apply C# methodologies and tools for software creation.
- Select essential C# controls and features to meet software design requirements.
- Examine the interoperability and functionality of C# software components.
- Generate C# design documentation aligned with user specifications.

## Topics covered

1. AI-assisted C# component design
2. C# programming fundamentals
3. Classes, objects and design controls
4. Functionality and interoperability
5. Design documentation and handover
